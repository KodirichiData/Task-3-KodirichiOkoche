# DecodeLabs Project 3: SQL Data Analysis

## Project Overview

This project was completed as part of the DecodeLabs Data Analytics Internship Program. The objective was to use SQL queries to extract meaningful business insights from an E-commerce sales dataset.

The project focuses on fundamental SQL concepts including data retrieval, filtering, sorting, grouping, and aggregation to support data-driven decision-making.

## Dataset Information

The dataset contains transactional information from an E-commerce platform, including:

* Order ID
* Order Date
* Customer ID
* Product Details
* Quantity Purchased
* Unit Price
* Payment Method
* Order Status
* Referral Source
* Coupon Code
* Total Price

## Objectives

* Retrieve data using SELECT statements
* Filter records using WHERE clauses
* Sort data using ORDER BY
* Group data using GROUP BY
* Perform aggregations using:

  * COUNT()
  * SUM()
  * AVG()
* Generate business insights from transactional data

## SQL Concepts Applied

* SELECT
* DISTINCT
* WHERE
* ORDER BY
* GROUP BY
* HAVING
* COUNT()
* SUM()
* AVG()

## Analysis Performed

### 1. Data Exploration

* Retrieved all records from the dataset
* Examined table structure and contents
* Counted total records

### 2. Order Analysis

* Identified delivered orders
* Filtered high-value transactions
* Analyzed orders by payment method

### 3. Revenue Analysis

* Calculated total revenue
* Determined average order value
* Evaluated revenue generated by products

### 4. Customer & Marketing Analysis

* Analyzed referral source performance
* Examined coupon code usage
* Assessed order distribution by status

### 5. Product Performance

* Identified top-performing products
* Measured revenue contribution by product
* Evaluated average quantity sold
